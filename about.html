About StackNova

A free one-tap online stacking game

StackNova is a free browser game about timing and precision. Blocks slide across the screen — tap to drop one, keep the overlap, and see how high your tower can grow. Land a perfect alignment and your combo builds; miss the tower entirely and the run ends.

The game

  • One-tap controls — click, touch, or Space. No tutorials needed.
  • Perfect-drop combos — precise alignment preserves width; three perfects in a row reward a wider block.
  • Runs anywhere — desktop and mobile browsers, no download, no account.
  • Local scores — your best is saved on your own device only.
  • English / 中文 — switch language anytime from the game page footer.

Built with

StackNova is built with TypeScript and the HTML5 Canvas API, with no game engine and no backend server. All gameplay happens locally in your browser.

Who makes this

StackNova is an independent game project created by a solo developer. It is kept free by advertising, in line with our Privacy Policy.

Where to play

The game is distributed through web game platforms and this website. Platform availability may change over time.

关于 StackNova

一款免费的单键在线堆叠游戏

StackNova 是一款关于时机与精度的免费浏览器游戏。方块在屏幕上方来回滑动——点击让它落下，保住重叠部分，看看你的塔能堆多高。精准对齐可积累连击，完全错开则本局结束。

游戏特色

  • 单键操作——点击、触摸或空格，无需教程。
  • 完美落层连击——精准对齐保留完整宽度，三连完美奖励更宽方块。
  • 随处可玩——桌面与手机浏览器，无需下载、无需账户。
  • 本地存档——最高分只保存在你自己的设备上。
  • 中英双语——随时在游戏页底栏切换语言。

技术栈

StackNova 使用 TypeScript 与 HTML5 Canvas API 构建，不依赖任何游戏引擎，也没有后端服务器。全部游戏过程都在你的浏览器本地完成。

关于开发者

StackNova 是由独立开发者个人创作的游戏项目，通过广告收入维持免费运营，详见隐私政策。
